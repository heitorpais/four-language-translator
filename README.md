# Four-Language Translator

A dictionary for English, German, French and Portuguese that runs in the browser and works offline.

- `app/`: the app (open `app/index.html` through a web server; see `HOSTING.md`)
- `app/data/`: the dictionary data, built from Wiktionary and Tatoeba (`LICENSES.md`)
- `build/`: the scripts that build the data (`build/README.md`)
- `docs/translator-app-spec.md`: the specification
